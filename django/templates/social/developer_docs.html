API приложений

← кабинет

Платформа на Django: OAuth-lite, signed_request, JSON API. Сторонний iframe/canvas не используется — только редирект на ваш сайт.

1. Запуск из canvas

Пользователь нажимает «Открыть с авторизацией» → редирект на ваш website_url:

https://somneniya.ru/?signed_request=SIG.PAYLOAD&user_id=123&app=somneniya

Проверка подписи: HMAC-SHA256(api_secret, PAYLOAD), сравнить с SIG (urlsafe base64).

2. OAuth-lite

Authorize:

GET /apps/<slug>/authorize?client_id=vd_…&redirect_uri=https://somneniya.ru/callback

После согласия → redirect_uri?code=vc_…&signed_request=…&user_id=…

Обмен code → token:

POST /api/oauth/access_token
client_id=vd_…
client_secret=…
code=vc_…
redirect_uri=https://somneniya.ru/callback

Ответ: {"access_token":"vat_…","token_type":"bearer","expires_in":2592000,"user_id":123}

3. Graph-lite

GET /api/app/me
Authorization: Bearer vat_…

GET /api/app/friends
Authorization: Bearer vat_…

Также: POST /api/app/verify_signed с client_id, client_secret, signed_request.
